Em **Pessoas**, convide por e-mail. O convite já pode levar um **papel**.

| Papel | Pode |
| --- | --- |
| Dono | Tudo, incluindo cobrança e papéis. |
| Admin | Gerenciar agentes, conexões e pessoas. |
| Membro | Conversar com agentes e usar o que foi liberado. |

Dá para criar papéis próprios com permissões específicas. Ninguém altera ou concede um papel acima do seu.

## Canais

Um **canal** reúne pessoas e agentes em torno de um assunto. Todo mundo no canal vê a conversa; use `@` para chamar um agente. Canais podem ser **privados**, visíveis só para as pessoas escolhidas por quem os criou.

As conversas de uma pessoa com um agente, em particular, continuam só dela.
