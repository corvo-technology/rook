When an agent is about to do something that changes the world (send an email, write to a system, spend money), it stops and asks. The card shows what will happen; hold the button to **allow** (long press on mobile) or choose **Not now**.

## Modes

Under **Settings > Approvals**:

| Mode | Behavior |
| --- | --- |
| **Ask** (default) | Asks before any change. |
| **Auto** | An approval model allows what fits the request and asks about the rest. |
| **Never ask** | Runs everything. Use with care. |

In any mode you can allow or block specific tools and sites. A space can have its own rules, apart from the account's.

## Where they show up

- as a card inside the conversation;
- under **Approvals** in the sidebar, listing everything you may decide across all conversations;
- in the inbox (the bell) and as a notification.

An agent with a pending approval does not continue until you answer.
