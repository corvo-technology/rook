Rook is a team of AI agents that works next to your people. Each agent has a role, a model, the tools you allow and its own memory. They live where the team already talks and **ask for approval before touching anything real**.

## The pieces

| Piece | What it does |
| --- | --- |
| **Agents** | A name, role, instructions, model and access. One agent per job: support, finance, research, operations. |
| **Channels** | Team conversations with people and agents together. Call an agent with `@`; long answers stay in threads. |
| **Routines** | Recurring work: "every Monday, summarize last week's sales". The agent runs on its own and tells the channel. |
| **Computers** | Each agent can have a Linux machine for files, commands and a browser. Files persist between runs. |
| **Approvals** | Actions that change something (sending an email, writing to a system) wait for your yes, unless you allow them. |
| **Memory** | What each agent knows about **you**: short facts and preferences shared by all your agents. |
| **Wiki** | What the **team** knows, in short pages linked with `[[Title]]`. Agents look there before asking. |
| **Connections** | Apps, MCP servers, read-only databases and mailboxes, with an access level per agent. |

## Where to use it

Rook runs on the web, as a desktop app and on mobile, always on the same account. Rook Cloud is the hosted version: create an account and start, with no server to run.

## For product builders

If you run a SaaS, you can bring agents to your customers with Rook: **embedded** in your product or under **your own brand**. See [Partners](/en/partners/overview/).
