---
title: "Your first agent"
description: "Create an agent, give it a role and talk to it."
sidebar:
  order: 2
---

1. Under **Agents**, choose **New agent**.
2. Give it a **name** and a one-sentence **role**: "Answers customer questions on WhatsApp".
3. Write the **instructions**: tone, what to do, what never to do. Short, concrete instructions work best.
4. Pick the **model**, or leave it on [Automatic](/en/agents/models/).
5. Under **Connections**, allow only what it needs.

When created, the agent introduces itself in a conversation: it says how it understood the role and asks for anything missing. Answer right there. To talk to it later, open its conversation or call it with `@` in a channel.

:::tip
Start with a narrow, useful agent. It is easier to widen a role than to fix an agent that does everything.
:::
